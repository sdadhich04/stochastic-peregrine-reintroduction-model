# Homework Model Studies

The AMATH 422 archive contains six homework artifacts. This folder separates the
recoverable executable code from artifacts that were present but not useful as
public source code.

| Homework | Public artifact | What it covers |
| --- | --- | --- |
| HW1 | `hw1_model-literature-warmup/README.md` | Literature-based model reading on COVID-19 intervention modeling; no executable code recovered. |
| HW2 | `hw2_age-structured-populations/README.md` | Assignment/submission evidence exists, but a source notebook or script was not recovered from the local archive. |
| HW3 | `hw3_owl-elasticity/elasticity_analysis.py` | Leslie-matrix growth analysis, stable age distribution, reproductive value, and elasticity decomposition. |
| HW4 | `hw4_markov-dwell-times/markov_dwell_times.py` | Ion-channel Markov-chain dwell-time simulation, state aggregation, survival curves, and exponential fitting. |
| HW5 | `hw5_ion-channel-spiking/spike_probability.py` | Stationary channel-state probabilities and stochastic/exact spike probability estimates across channel counts. |
| HW6 | `hw6_repressilator-network-motifs/repressilator_network_motifs.py` | Coupled repressilator ODEs and two-gene regulatory motif simulations. |

These scripts are refactors of notebook code in the recovered local course
archive. They are meant to be inspectable and runnable, not byte-for-byte copies
of the submitted notebooks.
